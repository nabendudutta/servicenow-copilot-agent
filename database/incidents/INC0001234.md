## Description
Multiple GitHub Actions pipelines are failing during the SonarQube analysis step. The workflow hangs for 10 minutes and then times out with error: `WARN: SCM provider autodetection failed`. This is affecting all repositories in the `payments-team` GitHub organisation. Approximately 47 PRs are blocked.

## Resolution Notes
Root cause was an expired SonarQube token configured as a GitHub Actions secret (`SONAR_TOKEN`). The token had a 90-day expiry that was not tracked.

**Fix applied:**
1. Generated a new SonarQube token in SonarQube → User → My Account → Security
2. Updated the `SONAR_TOKEN` secret at the GitHub organisation level (Settings → Secrets → Actions)
3. Re-ran failed pipelines — all passed

**Prevention:** Added token expiry monitoring alert in SonarQube admin. Documented token rotation procedure in KB0004521.

## Work Notes
- 09:30: Confirmed issue is not a GitHub Actions runner outage
- 10:45: Identified SonarQube token as suspect after reviewing runner logs
- 12:00: Token expiry confirmed — last rotated 91 days ago
- 14:00: New token deployed, testing in progress
- 14:32: All 47 pipelines re-triggered and passing
